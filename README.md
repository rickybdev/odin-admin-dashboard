
# Odin Project - Admin Dashboard

My attempt at the admin dashboard from the odin project.

This was a project mainly for putting grid learning into practice, they said to "lean into grid" as much as possible, and so I did exactly that. I forced myself to use grid even in places where flexbox felt like the better choice. Before this, I was never really a grid enjoyer. I'd always put it off and just default to using flexbox. This project has certainly changed that. 

Consider me a grid enjoyer :) 

## Thoughts & Rambles
It was really fun actually. Not as hard as I first pictured, but still fairly challenging considering my lack of practice with grid. I chipped away at it for a day, lots of breaks between so its hard to say how many hours. I tried to stick to the given design as much as possible as I believe this to be a valuable skill, being able to replicate a design based off of a picture alone. There is definitely still a lot I could clean up with my solution, my css file is quite the mess. I also could do with making it mobile friendly, though I understand that isn't within scope.
